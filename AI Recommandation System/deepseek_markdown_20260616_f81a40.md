# AI Recommendation Logic System

> Intelligent preference analysis, similarity scoring, and personalized recommendations – built with React, Flask, and modern AI concepts.

## 🚀 Features

- **User Preference Collection** – Multi‑select interests from 20+ categories.
- **100+ Item Dataset** – Courses, Books, Movies, Skills, Careers.
- **Weighted Similarity Engine** – Hybrid scoring (tag match × 0.6 + category match × 0.3 + rating factor × 0.1).
- **Explainable AI** – Match percentage, confidence level (High/Medium/Low), and reason for each recommendation.
- **Real‑time Dashboard** – Animated stat cards, interest distribution pie chart, category bar chart.
- **Search, Filter & Sort** – Search by name, filter by category, sort by score/rating.
- **Dark/Light Mode** – Glassmorphism UI with smooth theme transition.
- **Responsive Design** – Looks great on desktop, tablet, and mobile.
